🎸 Shuffle Hero

Guitar Hero-style shuffle trainer for card magic

📋 How to Use This Embed

For local testing (dev mode):

  1. Run npm run web in your shuffle-hero-react directory
  2. Open this HTML file in your browser
  3. Change iframe src to http://localhost:19006

For local testing (production build):

  1. Build: npm run build:web
  2. Serve: npx serve dist -l 8080
  3. Open this HTML file in your browser

For production deployment:

  1. Build your app: npm run build:web
  2. Deploy the dist/ folder to hosting (Netlify, Vercel, etc.)
  3. Replace the iframe src URL with your deployed URL

Tips:

  • The app works best in landscape mode on wider screens
  • Recommended minimum width: 800px
  • Touch the lanes to interact, or use the menu (≡) for settings
